# Historial de cambios del código

Este archivo sigue una estructura inspirada en *Keep a Changelog* y usa
versionamiento semántico. Las etapas anteriores a la adopción formal de Git se
reconstruyeron a partir de entregas y respaldos disponibles; no representan
etiquetas históricas verificables.

## [1.0.0] - 2026-08-13

### Agregado

- Documentación raíz del proyecto.
- Política de versionamiento y contribución.
- Guía de ejecución, despliegue, verificación y reversión.
- Plantilla de variables de entorno sin secretos.
- Documentación de los módulos centrales del backend y frontend.

### Estado funcional documentado

- API FastAPI con autenticación, roles y operaciones de negocio.
- Frontend Angular por perfiles de usuario.
- Base móvil Ionic/Capacitor.
- Gestión de productos, pedidos, entregas y notificaciones.

## [0.9.0] - 2026-08-05
